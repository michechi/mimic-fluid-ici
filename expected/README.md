# Aggregate reference results

`curves.csv` contains the exact two analysis curves and sensitivity grids used for the manuscript: 81 delta values and 101 chi values per sample. `cohort_counts.json` gives observed sample counts and percentages. Fitted baseline risks in the curves can differ from observed mortality proportions in the counts.

These files are aggregate regression references only. They contain no patient records or individual predictions. Each analysis is standardized to its own sample and fitted baseline.
